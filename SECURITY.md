# Security Policy

## Supported versions

Security fixes are made for the latest published SDK minor. The Developer API v1 compatibility policy and deprecation windows are
documented at <https://arcenciel.io/developers>.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability, leaked credential, privacy concern, or abuse path. Use this repository's
**Security** tab and choose **Report a vulnerability** to open a private GitHub Security Advisory.

Include the affected SDK and version, the smallest safe reproduction, expected impact, and any suggested mitigation. Remove real API keys,
personal data, private media, and production response bodies before attaching evidence.
